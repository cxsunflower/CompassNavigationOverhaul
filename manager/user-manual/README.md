# 使用手册

## 当前：相对偏移与自动高度
任务列表可以用横向/纵向偏移微调相对罗盘文字的位置，默认都是 0，并会继续跟随罗盘。**当前新构建范围为 -100～100、步长 5。**

“最大高度”已从菜单和当前活动实现中完整移除，列表高度只根据当前位置和安全底边自动适配；旧高度痕迹仅保留在历史反编译/退役工具中。

面板期望上限仍为110%，自动缩小下限仍为min(90,期望值)。新构建将原版标题装饰、杂项标题、正文、目标分隔线和目标名统一纳入不可见详情Box；原装饰和图案保留，整块内容共用原有出现/消失动画。较长文字会增加行数，放不下时按已有缩小/省略规则处理，不会把正文单独扩宽到装饰外。

验证与部署：高度坐标、缓存恢复、省略号预留和红框调试已纳入构建。最新修复已解决保存INI的UTF-8 BOM导致首个Debug节无法读取的问题，16:15完成DLL增量部署；两份嵌入式Compass保留。原生4/4、布局47/47、MCM11/11及完整包校验通过。Debug/Trace开启红框，Info关闭；新版本会记录有效日志级别与实际开关状态。**安装已验证，VR画面仍待复测**，用户配置未覆盖。
