# 界面与操作

本轮只读核对安装SWF及菜单与当前输入一致；下文描述当前实现，不保证游戏进程已加载或实机验收通过。本轮不执行部署。

## 菜单页面
菜单恢复正常后，在模组菜单中查找 `Compass Navigation Overhaul VR`。中文覆盖包提供“罗盘”“任务列表”“调试”三个页面。

- **罗盘**：地点/敌人标记、聚焦详情、距离单位、任务名称大小和距离大小。
- **任务列表**：新构建采用左右两列。左侧“显示”包含横向偏移、面板大小、室内/室外显示和拔出武器时隐藏；右侧“罗盘注视”包含注视开关、可见性、检测模式、角度、距离及掌心设置。“最大高度”控件已移除。
- **调试**：日志级别；英文级别名保留并附中文，便于对照日志。

## 常用操作
- 调整名称大小只控制名称部分；距离大小控制距离读数；面板大小一起缩放条目、文字与图标。
- 偏移设置（历史只读安装核验已一致，实机仍待验收）：仅保留横向偏移，范围-200～200、默认0、步长5；纵向偏移菜单与读取链路已删除，列表仍跟随罗盘。不要通过旧INI的QuestList fOffsetY调整位置；新DLL将忽略该键。X在Passenger模拟中可移动，游戏内效果仍待验收。
- 列表不再提供“最大高度”设置，当前活动配置和代码也已移除该项；可用高度会自动按安全区域计算。
- 注视有罗盘节点、右手和俯角模式。最新已部署修订中，启用“要求罗盘可见”时必须找到经核验的唯一 VR 罗盘节点；节点缺失不能仅靠低头回退显示。可见性要求关闭时仍允许既有注视回退。
- “需要注视罗盘”默认开启。若升级后仍显示关闭，可能是此前保存的设置覆盖了默认值；可以在 MCM 中手动开启并保存，不需要删除配置或存档。新布局与保存后的实际注视效果仍需 VR 验收。

## 列表如何阅读
新构建会把任务详情、目标分隔线和目标文字限制在原详情装饰内。较长的文字可能换成更多行；如果安全高度不足，仍会自动缩小或显示 `. . .`，不会为了减少换行而把正文扩宽到装饰外。此项已通过模拟测试，实际 VR 画面仍待验收。

当前实现还将原版标题装饰与杂项任务标题纳入同一个详情Box，使标题、正文和目标共用出现/消失动画。原有装饰和任务图案不会被删除，标题区域不受正文的局部遮罩影响；VR实际动画效果仍待验收。

当前省略逻辑会先检查哪些完整内容真正放不下，再决定是否显示`. . .`。当前实现使用紧凑三点：任一目标的文字或图标不能完整放下，该目标整条及后续内容隐藏，在其起始位置显示`. . .`；三个点仅占自身含黑边的高度，空图标槽没有独立高度，不再额外预留一行文字。如果它会挤掉原本可读的正文，则优先保留正文。仍然放不下的目标会按整行隐藏，不会强制显示到VR安全边界之外。若遇到异常省略，请按[调试指南](debugging.md)采集同一画面的布局日志。

新 Debug 在 MCM 选择 Debug／Trace 后显示 D/H/M/N/Q/F/V 空心边框、短 ID 和最多两行英文；Info 及以上关闭。没有逐行坐标标签或大摘要。隐藏对象与文字放不下的原因写入日志，不绕过共享父级隐藏；空任务列表仍能诊断实例存在性和逻辑视口。详见[调试指南](debugging.md)。普通诊断与菜单旧更新已部署；最新边框旁摘要、短 ID 限定显示带和 QL 原因已部署，待实机验收，应重启游戏后验证新屏幕输出。

进行中目标在前，已完成组按原始目标序号倒序，失败组在后。不是精确完成时间排序。分隔装饰已加强黑边，菱形保持原描边；实际 VR 效果仍需确认。

如果整个菜单都不出现，先看 [调试指南](debugging.md)，不要反复调整中文 JSON。当前项目记录已有 MCM Helper 成功注册证据，菜单异常需要以最新日志重新判断。
## Palm Compass 与任务列表门控
最新 VR 节点查找、列表门控诊断、边框旁摘要和短 ID 显示带限制均已构建回归，已部署，待实机验收；前次 Palm 隐藏修复实机未通过。

用户已明确：问题之一是罗盘还在手中，但任务列表不出现。当前不能断定是武器状态，也不能用旧 `Visible` 推断列表可见。新屏幕区分名称／距离动画 `Info shown` 与原生 `QL:` 原因；完整含义和采集步骤见[调试指南](debugging.md#罗盘还在但任务列表不出现)。

## Debug 字母与描述位置
