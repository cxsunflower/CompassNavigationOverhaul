# QuestList 独立标定模式：操作步骤

## 适用范围：共享HUD标定，不是独立掌上面板

本页“独立标定”指在**同一共享HUD路径中**使用不受QuestList自身遮罩影响的采样节点，不代表独立3D显示载体。此前得到的760～960候选连续带只用于现有内嵌模式，不能套用到新的独立NIF面板。

当前转向独立掌上原型时，不需要为了它继续重复本页的旧区域扫描；优先执行[独立面板测试](../docs/palm-test-panel.md#验收步骤)。只有继续排查内嵌模式或其显示载体变化时，才按需使用下列步骤。保留本页是为旧路径维护和取证，不代表此前已完成全宽/所有姿态标定。

旧测试哪些能复用、哪些只服务旧模式，见[架构转向复盘](../docs/palm-test-panel.md#架构转向复盘旧边界测试的价值与适用范围)。

## 先做第一轮

1. **退出游戏。** 本次更新包含 DLL，第一次使用必须重新启动。
2. 在 MO2 左侧找到当前启用的 **Compass Navigation Overhaul VR 主模组**，右键打开模组文件夹。
3. 打开其中的 `SKSE/Plugins/CompassNavigationOverhaulVR.ini`，先备份该文件。
4. 找到已有的 `[Debug]` 分节，在该分节中加入下面五行。**不要清空文件，不要重复添加 `[Debug]`，保留原来的其他设置。**

```ini
bCalibrateQuestList=1
uCalibrationAxis=0
fCalibrationStart=700
fCalibrationStep=40
fCalibrationCross=512
```

如果文件没有 `[Debug]`，在文件末尾新建这个分节，再加入五行即可。

5. 保存后从 MO2 启动游戏。保持一项任务处于追踪状态，像平时看 QuestList 一样看向罗盘/目标，使罗盘详情所在的父级处于显示状态。
6. 普通 QuestList 和普通 HUD Debug 叠加层应暂时消失，改为青色/橙色十字标记及 `Y=...` 坐标。第一轮最多有 9 个：**700、740、780、820、860、900、940、980、1020**。
7. **截图要包含整块罗盘显示区域，以及之前出现上方残片的位置。** 不要只截中间正常的标记。把截图发回来；不需要自己计算边界。

> 默认开关为关。安装时保留了你的用户 INI，因此不会自动开启标定。若所有标记都没有出现，先不要认为整个范围不可见：确认任务/罗盘详情正在显示，然后检查日志中的 `[QuestListCalibration] enabled=true`。

## 各项设置的意思

| 设置 | 含义 |
|---|---|
| `bCalibrateQuestList` | 1 开启，0 关闭；与原有日志级别独立 |
| `uCalibrationAxis` | 0：沿 Y 轴采样；1：沿 X 轴采样 |
| `fCalibrationStart` | 第一个十字的坐标，范围 0～1024 |
| `fCalibrationStep` | 相邻十字的间距，范围 2～80；默认 40 |
| `fCalibrationCross` | 固定的另一轴坐标：测 Y 时为 X，测 X 时为 Y；范围 12～1012 |

坐标是 **SWF 根坐标**，不是截图像素、视野角度，也不是米。判断依据是十字中心是否连续、完整显示，不能仅凭坐标文字被裁断来判断。

## 后续测左右边界

先完成第一轮，让我们找出一个连续可见的 Y。之后再把它设为 `fCalibrationCross`，沿 X 轴扫描。例如 **仅在确认 Y=860 可见后** 使用：

```ini
uCalibrationAxis=1
fCalibrationStart=200
fCalibrationStep=80
fCalibrationCross=860
```

这会采样 X=200、280、360、440、520、600、680、760、840。再按结果调整起点。

上下边界也应在不同 X 位置复测，例如将第一轮的 `fCalibrationCross` 分别设为 400、600。只有中心列可见，不能证明整个矩形区域都安全。

细扫时可缩小步长，但标签可能重叠；先完成步长 40 的截图，再根据结果选择下一轮，不要一开始就用步长 2。

## 游戏运行中换一轮参数

首次安装重启后，后续改这五个 INI 值可以热重载：

1. 在游戏中打开一个菜单。
2. 在外部编辑器修改同一个 INI 并保存。
3. 返回游戏关闭菜单，触发重新读取。
4. 看向同一个罗盘目标，再截图。

若没有生效，退出并重启确认；不要反复改面板大小作为标定步骤。如果同名标定键已存在于更高优先级的 `MCM/Settings` 保存文件，它会覆盖 SKSE 用户 INI；不要在多个文件重复配置这些键。

## 关闭与恢复

将同一文件中的这一行改成：

```ini
bCalibrateQuestList=0
```

保存后开关菜单，或重启游戏。标记会移除，正常 QuestList 和原有调试状态恢复。标定不会改写任务内容、面板大小、偏移、原始装饰或 VR 网格。

## 这项测试能确认什么

标记与 QuestList 共享 Target 父级，但使用独立兄弟节点，不经过 QuestList 自身的遮罩、自动缩放、自动移动或 8% 保护线；正常的上级可见性、渲染路径仍保留。

因此它用于观察真实路径中哪些根坐标能连续显示，不会把人为设置的 942.08 误当成测量结果。需要在相同视角及不同罗盘姿态下复测。它不是自动边界检测器，也没有解析/修改 UV 网格；实际边界要结合截图、日志及后续网格检查确定。
