# 组件如何配合

```text
游戏中的任务和地点 → 罗盘插件 → HUD 上的标记与任务列表
菜单设置 → MCM Helper → 罗盘插件的设置
中文覆盖包 → 中文菜单文案
```

| 组件 | 对用户的作用 |
|---|---|
| SKSEVR | 加载原生插件 |
| Infinity UI / HUD 资源 | 加载罗盘和任务列表界面 |
| SkyUI VR / MCM Helper | 提供模组菜单与设置支持 |
| 主包 | 罗盘插件、界面、默认配置与菜单 ESP |
| CHS 包 | 覆盖英文菜单配置，不能单独安装 |

因此“罗盘能显示”不保证“MCM 菜单正常”；两条链路需要分别验收。[开发架构](../docs/architecture.md)。
