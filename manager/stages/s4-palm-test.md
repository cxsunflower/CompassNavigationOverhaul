# S4 独立掌上测试面板

- 授权：用户选择 B，并要求先做独立测试面板；不修改 Palm，不把现有任务列表直接迁移。
- 实现：原生只读观察罗盘变换，独立 RoomNode 子节点、独立 NIF/DDS；尺寸/偏移不继承 Palm 缩放；可关闭、读档重建、候选不明确时隐藏。
- 默认：发布实验 INI 为关闭；不增加 MCM 设置，不改原 Compass SWF，不恢复旧 UV 补偿。
- 已验证：网格生成后可重新载入，4 个顶点/2 个三角形；原生变换模板 288 组数学用例通过；本项目 DLL 完整编译与打包通过，主包18/中文1文件及ZIP一致；既有56项AS2和24项Python回归通过。
- 未验证：VR 可见性、真实朝向、快速手部运动、实际节点更新顺序、读档恢复。静态面板不等于独立 QuestList 渲染管线完成。
- 部署：用户明确选择“部署并启用”；现有主包DLL+4个新文件哈希验证，独立INI设为1；源码/发布默认仍为0。111个保护文件（含Palm、原SWF/INI、CHS和MO2配置）未变。
- 回滚：备份`_patch_work/compass-palm-test-20260910-073300`；退出游戏后恢复原DLL，并移除manifest中标明原先不存在的4个文件。仅隐藏测试可设`bEnabled=0`。未暂存、提交或push。
- 构建工具：外置nifly提交`f445ebc2e6ace115bbc2de56c70c3562914c5c15`；Linux工具编译内存不足后改在本机Windows构建，未改依赖源码。
- 验证边界：初次Node调用缺少反编译路径而未运行测试；补齐参数后56/56通过。没有把静态测试称为实机通过。
