# Compass Navigation Overhaul VR

## 当前：QuestList 源码模块化与布局验收
详情组件已统一为 `DetailBox → Header + DetailBody`：原版 Title 整体作为 Header 保留，原18帧动画改为驱动外层 Box；正文、分隔装饰和目标行在 Body 中统一排版。原装饰决定自然宽度，Box 汇总完整逻辑高度，现有安全区负责缩小/省略，局部遮罩仅兜底极端绘制越界。原始素材、任务类型图案及杂项标题保留，新构建待 VR 验收。
MCM 任务列表页已改为左右分栏：左侧“显示”，右侧“罗盘注视”。`bRequireLookingAtCompass:QuestList` 的默认开启契约已核对并补齐 SKSE 默认 INI；已有用户保存值仍优先，不强制改写。
任务列表使用 `fOffsetX:QuestList` / `fOffsetY:QuestList`，默认均为 0；**当前源码、MCM、SWF 与新打包产物已统一为 -100～100、步长 5**。C++ 与 AS2 都做同一边界 clamp；旧 `fPositionX/fPositionY` 仍仅作为位置兼容项保留。

最大高度设置的活动链已完整移除：默认 INI、C++ 变量/分发/注册、C++→AS2 接口、AS2 `SetMaxHeight` 入口及旧兼容行为测试均已删除；布局继续只按偏移后的面板起点与安全底边自动计算可用高度。`decompiled/` 与已退役的原版字节补丁校验脚本保留历史参考，不属于当前运行/构建链。

面板期望上限仍为 110%，自动缩小下限仍为 min(90,期望值)；现在固定装饰内宽→自动缩小→整段/整行省略，安全底边和名称原位渐变不变。偏移过大时面板可能超出安全区而隐藏，应从 0 开始小幅调整。

验证与部署：已将QuestItem/QuestItemList拆为13个职责模块，构建期组合回原两个入口，71个函数体与本轮冻结基线逐字一致；源码说明见[模块目录](../swf/questlist/README.md)。10/10模块测试、45/45反编译布局模拟、3/3包装器、MCM10/10及三项SWF哈希检查通过；27项QuestList源码/产物清单和主包/CHS完整性校验通过，`build.bat`成功（原生代码未变，DLL无需重新编译）。**本轮新包未部署、未VR验收**；MO2未覆盖，已安装版本沿用13:09记录。提前省略修复与红框调试保留，实际VR可视边界仍待采样。Git未暂存/提交，原始素材与`decompiled/`未改。
