# 独立掌上测试面板

## 范围

用户选择 B：罗盘继续由 Palm 控制；本项目新增独立任务面板，跟随位置/朝向，不继承 Palm 缩放。本轮只实现**静态测试面板**，不接 QuestList 数据、不替换现有显示路径、不修改 Palm 的安装文件。

## 架构转向复盘：旧边界测试的价值与适用范围

### 结论：不是全盘作废，也不是所有成果都能照搬

用户提出“独立显示的话，昨天测试边界的活是不是白干了”。应区分**共享载体的具体测量结果**与**内容布局的通用修复**，不能用“都有用”掩盖迁移成本，也不能把旧路径已解决的问题当成无效工作。

| 既有成果 | 内嵌模式中的价值 | 独立面板中的处理 |
|---|---|---|
| 根坐标 Y=760～960 候选连续显示带、接缝避让、共享 HUD 窗口钳制 | 当前完整 QuestList 仍依赖这些约束；用户已确认跨区残片不再出现 | 不沿用具体数值，不把它当成独立面板的通用边界；保留于内嵌模式 |
| 采样标记、截图与运行时坐标对照 | 说明共享显示路径存在分段，排障不能只盯文字排版 | 复用取证方法，不复用旧载体的测量结果；这也不是完整 UV 解析或所有姿态安全证明 |
| 测量、布局、裁切统一坐标系；旋转/缩放父级变换测试 | 避免根坐标与局部坐标混用 | 复用原则和适用测试；按独立载体的坐标契约调整实现 |
| 完整目标行/菱形裁切、换行、省略号不挤掉最后可读目标 | 修复实际内容丢失和半行显示 | 作为迁移后的内容验收项，换用新可用区域后重新验证，不宣称现代码可直接无改动搬入 |
| 原版装饰、完成排序、原位淡入等内容行为 | 维持现有视觉和交互要求 | 保留需求与相关代码资产；与新渲染生命周期一起回归 |
| 90% 自动缩小下限、110% 期望上限 | SWF 内部布局策略 | 不等于最终 VR 物理字号；独立面板物理尺寸应与内容适配分别设计 |

**准确表述：边界数值成为旧模式的兼容成果；内容布局和裁切修复继续有价值。** 当前内嵌模式仍在使用，尚未被静态原型替代。

### 为什么现在转向独立载体

原目标是在保留罗盘跟随和现有显示路径的前提下修复溢出，因此标定共享区域有当时的用途。后来用户明确选择 B：“小罗盘 + 跟随掌上的独立任务面板，尺寸不受 Palm 缩放”。这一目标涉及外层 3D 载体的缩放所有权，不只是 AS2 字号或窗口尺寸。

共用显示表面上的内容会一起受到外层节点缩放，Flash 内部反向放大也不会增加承载表面的可用区域。采样结果为评估共享路径限制提供了依据，但不能据此宣称已解析完整 UV 或独立方案已经运行成功。

### 可以更早做好的事

如果一开始就明确“独立掌上显示、尺寸不受 Palm 影响”，应更早比较共享 HUD 与独立载体，并先做小型原型；这样可减少为最终独立路径服务不了的边界试探。此前分析没有足够早说明承载限制和方案代价，这是需要改进的方案评估过程。

不能倒推为“此前全部测试都必须做”，也不能把后来才明确的需求伪装成最初既定目标。后续遇到共享显示区域反复越界或外层缩放与内容可读性冲突，应先确认用户目标和变换所有权，再决定继续标定还是评估载体分离。

### 迁移门槛与保留策略

1. **保留旧路径**：当前完整 QuestList、760～960 候选带和相关测试继续保留，不因新建静态面板而删除或放宽。
2. **先验原型**：独立 NIF/DDS 仅验证载体、跟随、尺寸/间距隔离、显隐和读档恢复；目前已部署，VR 结果尚未反馈。
3. **再接 UI**：独立 Scaleform 纹理输出、任务数据桥接、字体/分辨率、透明度和生命周期尚未完成。静态模型可见也不代表这些问题已解决。
4. **重建边界契约**：独立任务 UI 使用自身模型/纹理/视口对应的矩形区域与必要内边距，重新验证内容与裁切；不得机械套用旧 760～960，也不能假定独立矩形永不遮挡、永不溢出。
5. **最后切换**：完整任务显示验收后，再实现两种模式互斥与回退；在此之前不宣布 B 完整交付，不以本轮文档更新授权删除旧实现。

## 实现

- `source/palmtest/`：独立场景节点、HIGGS 回调观察者、配置和生命周期。
- `source/MessageListeners.cpp`：转发 SKSE 消息；其他 UI 路径保持原样。
- `assets/main/meshes/CNO/PalmTest.nif`：原创 24×12 游戏单位的双面平面，独立 UV，不引用共享 HUD 贴图。
- `assets/main/textures/CNO/PalmTest.dds`：原创不透明标尺、四色角标和 `PALM TEST / FIXED SIZE / NO QUEST DATA` 标签。
- `assets/main/SKSE/Plugins/CNO_PalmTest.ini`：独立实验开关，发布默认关闭，每秒读取一次。
- `tools/palmtest/`：网格/纹理生成器、原生变换测试和依赖声明。

Palm 公开源码在 `kPostLoad` 向 HIGGS 注册回调；本原型在 `kPostPostLoad` 注册到同一回调列表末尾。HIGGS 当前公开实现按插入顺序调用。此结论基于所审查源码，不保证未来版本保持顺序；快速移动手掌时仍需实机排查滞后一帧。

只接受祖先路径含 `skyvr_hmd_compass.nif` 的 `skyVR_HUD01`。多个候选时不猜测，隐藏并写日志。缓存用当前 VR 根检查；读档/新游戏请求在帧回调中释放旧面板并重找。找不到 Palm/HIGGS 时不注册功能，不影响现有 Compass。

独立模型挂在 `RoomNode`，不挂在罗盘下面。世界变换为：

```text
rotation = compass.world.rotation
position = compass.world.position + rotation × configuredOffset
scale = configuredWidth / 24
local = inverse(RoomNode.world) × desiredWorld
```

**位置偏移和尺寸都不乘罗盘缩放**。这是独立节点的坐标换算，不是恢复旧的 Palm UV/网格补偿；原 Compass 节点、UV、SWF、安全带和 QuestList 90/110 设置均未修改。

## 启用与关闭

安装新增模型、纹理及本项目 DLL 后，在游戏 Data 对应的 `SKSE/Plugins/CNO_PalmTest.ini` 设置：

```ini
[PalmTest]
bEnabled=1
fWidth=24
fOffsetX=0
fOffsetY=-14
fOffsetZ=0
```

- `fWidth`：4～80 游戏单位，面板高度固定为宽度的一半。不是厘米，也不是固定视角字号。
- XYZ 偏移：-100～100 游戏单位，使用罗盘旋转坐标轴。模型在 XY 平面，正 Z 为正面。
- 修改设置约一秒生效；`bEnabled=0` 会隐藏并移除测试节点。模型加载失败后关闭再开启可重试。
- 无 MCM 项目，不改已有用户 INI；独立测试 INI 只用于这一阶段。
- 深度测试开启，可能被手/场景物体遮挡；双面是为定位朝向问题，背面文字会镜像。

## 验收步骤

1. 保持现有 Compass 和 QuestList 正常，翻掌显示罗盘，找到青色边框面板。
2. 保持手掌距眼睛基本不变，将 Palm Scale 在 0.05 / 0.12 / 0.30 间切换：罗盘变大小；测试面板宽高与独立偏移距离应不变。
3. 横移、抬高手掌、转向和快速移动，检查位置/方向跟随与抖动、滞后。
4. 翻掌隐藏罗盘；打开菜单/暂停；回到游戏，检查面板显隐恢复。
5. 读取同一存档、另一个存档，确认无重复面板或残留；主菜单不显示。
6. 将测试面板 `fWidth` 改为 48，再恢复 24：只有面板改变；关闭开关应移除。
7. 检查本项目日志 `[PalmTest]`：候选唯一、创建成功、`anchorScale` 变化而 `panelWorldScale` 保持、`poseError` 接近零。

日志中的 `width` 是目标尺寸；`panelWorldScale` 才是更新后的节点读数。数学/编译检查不证明 VR 渲染或像素尺寸正确。

## 已知边界与后续

- 这是独立 **3D 静态表面** 原型，不是完成的独立 Scaleform/QuestList 渲染器。
- 可见性观察当前节点及祖先的隐藏/裁切状态，并在暂停/主菜单隐藏；尚不复制材质透明度、GFx 透明度或所有特殊菜单的显隐规则。
- 模型加载、朝向、有效可见状态、读档恢复与回调顺序仍需实际 VR 验收。
- 手离眼睛越远看起来越小属于透视；本原型不补偿距离。
- 固定尺寸不代表纹理无限清晰：本原型纹理为 512×256，接入正文时需重新设计分辨率和字体。
- 只有原型验收后，才评估独立 Scaleform 纹理输出、数据桥接和内嵌列表的互斥切换。本阶段不能据此宣布 B 方案完整交付。

## 构建与来源

网格工具使用外置 nifly（只在构建工具中链接，不进入游戏 DLL）；设置 `NIFLY_SOURCE_DIR` 指向外部源码。常规 `build.bat` 使用已生成资源，不要求玩家安装 nifly。

```text
cmake -S tools/palmtest -B build/palmtest-asset -DNIFLY_SOURCE_DIR=<nifly-source>
cmake --build build/palmtest-asset --config Release
ctest --test-dir build/palmtest-asset -C Release --output-on-failure
<asset-tool> assets/main/meshes/CNO/PalmTest.nif
python tools/palmtest/make_texture.py assets/main/textures/CNO/PalmTest.dds
build.bat
```

仅 HIGGS 接口声明/请求适配器复用 Palm 仓库的 MIT 代码；许可证随发布资源保留。没有复制 Palm 的场景变换实现或修改其二进制文件。

- 审查 Palm 源码：`https://github.com/LivSterling/Palm-Compass-VR`，提交 `7bc931fbc630b71eb5aec4a200ac7480cbf56811`。
- HIGGS 回调顺序：`https://github.com/adamhynek/higgs`，`src/pluginapi.cpp`。
- nifly：`https://github.com/ousnius/nifly`；构建时提交号以构建记录为准。
