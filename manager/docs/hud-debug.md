# HUD Debug：少量界面文字，详细日志

## 状态与启用

2026-09-10 已完成源码替换、DLL/SWF 构建和回归，**尚未部署，VR 实机未验收**。旧的逐行红框、坐标摘要及绕过父级隐藏的显示行为已删除；MCM 日志级别联动按用户要求保留；历史记录不再是使用说明。边界校准仍是独立工具。

在 MCM「调试 → 日志级别」选择 Debug 或 Trace，关闭菜单后开启全部普通 HUD 边框、中文状态和详细日志；选择 Info 或更高级别关闭。发布默认 Info，因此默认关闭。不需要手改 INI；原三层 INI 优先级和 BOM 兼容读取不变，不删除或重写用户保存文件。独立 bDebugOverlay 设置已移除。

原生直接采用 MCM 配置的日志级别，Debug／Trace 时写入 `[HUDDebug]` 诊断。`bCalibrateQuestList` 不受该开关控制，同时开启校准时暂时隐藏普通叠加层。

## 游戏界面

| ID | 对象 | 颜色／线型 |
|---|---|---|
| D | 距离文字 | 青色实线 |
| H | 高度箭头 | 橙色实线 |
| M | 聚焦的罗盘标记 | 白色实线 |
| N | 名称文字 | 绿色实线 |
| Q | QuestList 可见内容的保守逻辑包围范围 | 紫色实线，与逻辑视口相交 |
| F | QuestList 完整逻辑内容 | 紫色虚线 |
| V | 允许的逻辑视口 | 黄色虚线；不是实测 UV 窗口 |

- 不画实心面板，不逐目标行加标签，不显示坐标表。
- 屏幕最多两行中文：`距离 150% · 淡入中`；仅距离与标记矩形重叠时显示红色 `与标记边界重叠 …`。数值是根坐标 AABB 最小轴穿透量，不是像素遮挡深度。
- 描述使用固定候选位置，并限制在项目既有连续显示带内；不跟着动画跑。当前位置被内容占据、字体测量超限或没有可用位置时隐藏，原因记入日志。连续显示带也不代表全宽／全部姿态已标定。
- 短 ID 按 D、H、M、N、Q、F、V 优先级尝试四个邻近位置，避让内容、描述和已放置标签；无安全位置则省略。
- 线框每帧重画；描述约每 200ms 更新，显隐、动画阶段、重叠等状态变化立即刷新。
- 根级叠加层虽不参与列表测量，仍显式遵守罗盘、DirectionRect 和共享父级的 `_visible`／`_alpha`。隐藏对象原因只写日志，不强制显示其边框。无任务条目时，距离、箭头、名称、聚焦标记仍可观察。

## 日志与局限

日志文件为 Windows 实际文档目录下 `My Games/Skyrim VR/SKSE/CompassNavigationOverhaulVR.log`，搜索 `[HUDDebug]`、`schema=HUDDebug/1`。

- 开启／实例重建／设置应用：完整快照。状态转变在 AS2 当前观察帧入队，原生罗盘更新钩子最多约每 100ms 取走；这不是严格实时文件写入承诺。
- 动画／几何变化采样上限约 5Hz；静止且未变化不重复记录。条目动画摘要参加采样变化比较，但不把每个 alpha 变化当作立即事件。
- 包含对象存在性、路径、可见性与隐藏原因、alpha、当前帧、请求和实际缩放、逐级父变换、局部矩形、根坐标四角／AABB、Q/F/V、适配与省略原因、可见／总行数、对象间重叠与有符号间隙、文字抑制原因。
- 完整事件额外记录最多 8 项任务、每项最多 24 行的几何细节；超出数量显式标注。单快照最多 32Ki 字符，队列最多 12 项；溢出／截断会记原因。原生传输另有 512KiB 安全上限。采样不重复打印全套目标行。
- 动画标签与参考矩阵由构建时从实际 sprite 136 读取：IdleHide 第 1 帧、FadeIn 第 2 帧、IdleShow 第 12 帧、FadeOut 第 13 帧；本次 Distance 的 IdleShow Y 为 -40.7 本地单位。没有跳转播放头来测量。
- `stationaryReference=authored-IdleShow-current-ancestors` 表示：原时间轴的静止 Distance 矩阵＋当前文字缩放和当前祖先变换。它不是物理世界静止位置，不抵消共享父级动画。
- 缺失数据使用 `missing`／`n/a`，不伪造零。矩形、逻辑裁剪、滤镜之外的测量均不证明实际像素遮挡，也无法单凭这些数据确定 VR 网格／UV 边界。Q/F 是保守逻辑包围范围，不是逐像素轮廓。

## 源码职责

- `swf/compass/Debug.as`：唯一普通观察器、四角转换／多边形裁剪、线框、避让、状态和队列。由 `Compass.as` 在构建时纳入原时间轴，不增加外部运行时 SWF。
- `swf/questlist/list/Debug.as`：只读 `GetDebugObservation`／`GetDebugDetails`，不调用 Update/FitLayout。
- `swf/questlist/item/Debug.as`：只读 `GetDiagnosticRegions`，仅供详细日志使用。
- `swf/questlist/list/Calibration.as`：独立十字校准与卸载清理，保留原工具行为。
- `source/ui/SettingsLifecycle.cpp`：应用设置和有界日志传输；`source/hooks/Markers.cpp` 在原罗盘更新后调用，不持有跨帧 GFx 对象。
- `tools/build_compass_swf.py`：跟踪观察器源码哈希并读取实际动画元数据；QuestList 构建继续验证模块清单、原 ABI 和装饰。
