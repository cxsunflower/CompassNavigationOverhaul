# HUD Debug：少量界面文字，详细日志

## 状态与启用

本轮提交前只读核对：两份安装Compass、中英文MCM及两份默认INI与当前源输入一致，打包目录的对应文件也一致。此前发现过来源未确认的外部更新；本轮仅冻结当前文件，不把一致性冒充由本轮执行的部署或游戏加载证明。 当前源码的Q/F/V线段保护与紧凑省略标记仍待实机验收；不沿用旧日志判断现在是否已加载。

在 MCM「调试 → 日志级别」选择 Debug 或 Trace，关闭菜单后开启全部普通 HUD 边框、英文状态和详细日志；选择 Info 或更高级别关闭。发布默认 Info，因此默认关闭。不需要手改 INI；原三层 INI 优先级和 BOM 兼容读取不变，不删除或重写用户保存文件。独立 bDebugOverlay 设置已移除。

原生直接采用 MCM 配置的日志级别，Debug／Trace 时写入 `[HUDDebug]` 诊断。`bCalibrateQuestList` 不受该开关控制，同时开启校准时暂时隐藏普通叠加层。

## 游戏界面

| ID | 对象 | 颜色／线型 |
|---|---|---|
| D | 距离文字 | 青色实线 |
| H | 高度箭头 | 橙色实线 |
| M | 聚焦的罗盘标记 | 白色实线 |
| N | 名称文字 | 绿色实线 |
| Q | QuestList 可见内容的保守逻辑包围范围 | 紫色实线，与逻辑视口相交 |
| F | QuestList 完整逻辑内容 | 紫色虚线 |
| V | 允许的逻辑视口 | 黄色虚线；不是实测 UV 窗口 |

- 不画实心面板，不逐目标行加标签，不显示坐标表。
- 屏幕最多两行英文：`Distance 150% | Info shown`；第二行 `QL: ...` 表示原生列表门控（weapon/cell/no-quest/compass/gaze/settling/requested/missing-list/unknown），重叠时追加 `Overlap ...`。数值是根坐标 AABB 最小轴穿透量，不是像素遮挡深度。
- 描述优先放在聚焦标记 M 边框右侧的固定槽位，右侧无安全空间时才尝试左侧，并限制在项目既有连续显示带内；不跟着动画跑。当前位置被内容占据、字体测量超限或没有可用位置时隐藏，原因记入日志。连续显示带也不代表全宽／全部姿态已标定。
- 短 ID 按 D、H、M、N、Q、F、V 优先级，依次尝试自身边框右、下、左、上；候选完整落在既有显示带内并避让内容、摘要及标签。没有安全位置或显示带未知时隐藏并记录 no-safe-label-slot，不远距离夹取坐标。Stage 内不等于实际 VR 显示安全。
- 省略标记现为无滤镜的三点MovieClip，Q集合与视口遮罩都使用实际矢量getBounds，不再套用TextField宽高。
- Q/F/V仅绘制显示带内的原始线段，不补画底部裁剪边；显示带未知或无效时隐藏这三类框线。日志保留完整F／Q／V几何，D/H/M/N仍使用原Stage保护。不宣称该候选带在所有VR姿态下安全。
- 线框每帧重画；描述约每 200ms 更新，显隐、动画阶段、重叠等状态变化立即刷新。
- 根级叠加层虽不参与列表测量，仍显式遵守罗盘、DirectionRect 和共享父级的 `_visible`／`_alpha`。隐藏对象原因只写日志，不强制显示其边框。无任务条目时，距离、箭头、名称、聚焦标记仍可观察。

`Info shown` 仅表示名称／距离动画处于 IdleShow，不等于 QuestList 已渲染；`QL: requested` 仅表示原生已请求显示，实际 AS2 内容、父级可见性和 VR 渲染须分别核查。`[QuestListGate]` 在原因变化或约 2Hz 记录武器原始布尔值、隐藏设置、策略门控、任务焦点、注视／可见性要求与结果、节点是否找到及节点可见性。

固定 HUD 诊断文案及原生 Hook 检查日志统一英文。任务名称、目标内容、MCM 翻译及用户原始数据不被翻译；少量界面文字与有界详细日志的规则不变。

## 英文状态释义

原因按显示门控顺序报告，详细日志保留各条件，不将首个失败原因当作唯一可能问题。

| 英文状态 | 含义／下一步 |
|---|---|
| `Info shown` | 名称／距离动画为 IdleShow，不是任务列表可见状态。 |
| `QL: weapon` | 游戏报告武器拔出，且开启对应隐藏设置；空手外观不能替代这个读数。 |
| `QL: cell` | 当前单元格不可用，或室内／室外显示设置未通过。 |
| `QL: no-quest` | 当前焦点没有对应任务数据。 |
| `QL: compass` | 可见性要求未通过；可能是节点隐藏、缺失、候选不唯一或 Flash 明确隐藏，不只表示手势隐藏。 |
| `QL: gaze` | 注视门控未通过；对照模式、角度和距离日志。 |
| `QL: settling` | 满足显示条件，正在等待稳定聚焦。 |
| `QL: requested` | 原生已经请求显示；仍需核对实际内容、AS2 父级显隐和 VR 渲染。 |
| `QL: missing-list` | 原生任务列表实例不可用。 |
| `QL: unknown` | SWF 尚未收到原生原因，不能猜测为可见或隐藏。 |

## 日志与局限

日志文件为 Windows 实际文档目录下 `My Games/Skyrim VR/SKSE/CompassNavigationOverhaulVR.log`，搜索 `[HUDDebug]`、`[QuestListGate]`、`[QuestListGaze]`。用 Windows MyDocuments 特殊目录定位，不硬编码用户文档路径；步骤见[调试指南](../user-manual/debugging.md)。

- 开启／实例重建／设置应用：完整快照。状态转变在 AS2 当前观察帧入队，原生罗盘更新钩子最多约每 100ms 取走；这不是严格实时文件写入承诺。
- 动画／几何变化采样上限约 5Hz；静止且未变化不重复记录。条目动画摘要参加采样变化比较，但不把每个 alpha 变化当作立即事件。
- 包含对象存在性、路径、可见性与隐藏原因、alpha、当前帧、请求和实际缩放、逐级父变换、局部矩形、根坐标四角／AABB、Q/F/V、适配与省略原因、可见／总行数、对象间重叠与有符号间隙、文字抑制原因。
- 完整事件额外记录最多 8 项任务、每项最多 24 行的几何细节；超出数量显式标注。单快照最多 32Ki 字符，队列最多 12 项；溢出／截断会记原因。原生传输另有 512KiB 安全上限。采样不重复打印全套目标行。
- 动画标签与参考矩阵由构建时从实际 sprite 136 读取：IdleHide 第 1 帧、FadeIn 第 2 帧、IdleShow 第 12 帧、FadeOut 第 13 帧；本次 Distance 的 IdleShow Y 为 -40.7 本地单位。没有跳转播放头来测量。
- `stationaryReference=authored-IdleShow-current-ancestors` 表示：原时间轴的静止 Distance 矩阵＋当前文字缩放和当前祖先变换。它不是物理世界静止位置，不抵消共享父级动画。
- 缺失数据使用 `missing`／`n/a`，不伪造零。矩形、逻辑裁剪、滤镜之外的测量均不证明实际像素遮挡，也无法单凭这些数据确定 VR 网格／UV 边界。Q/F 是保守逻辑包围范围，不是逐像素轮廓。

## 源码职责

- `swf/compass/Debug.as`：唯一普通观察器、四角转换／多边形裁剪、线框、避让、状态和队列。由 `Compass.as` 在构建时纳入原时间轴，不增加外部运行时 SWF。
- `swf/questlist/list/Debug.as`：只读 `GetDebugObservation`／`GetDebugDetails`，不调用 Update/FitLayout。
- `swf/questlist/item/Debug.as`：只读 `GetDiagnosticRegions`，仅供详细日志使用。
- `swf/questlist/list/Calibration.as`：独立十字校准与卸载清理，保留原工具行为。
- `source/hud/SceneNodes.cpp`：VR 根与 compass NIF 路径核验、唯一候选、缓存归属、独立重试及可见性否决。
- `source/hud/Gaze.cpp`／`QuestPresentation.cpp`：独立可见性和注视门控、原生 QL 原因及限频日志，不用动画状态代替显示结果。
- `source/ui/SettingsLifecycle.cpp`：应用设置和有界日志传输；`source/hooks/Markers.cpp` 在原罗盘更新后调用，不持有跨帧 GFx 对象。
- `tools/build_compass_swf.py`：跟踪观察器源码哈希并读取实际动画元数据；QuestList 构建继续验证模块清单、原 ABI 和装饰。
