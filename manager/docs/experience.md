# 可复用经验

## 配置契约
- 标签：`#配置` `#测试`；日期：2026-09-08。
- 现象：中英文结构一致性测试通过，但名称/距离默认值放在错误 INI 分组。
- 根因：仅比较 JSON 译文不能验证 `key:section` 与实际设置文件契约。
- 方法：跨 JSON、INI、C++ 注册/回调校验，并用错误分组、默认值不符的反例测试。
- 原则：翻译正确与设置可用是不同验收项。[关联 S2](../stages/s2-mcm.md)。

## MCM 布局与默认值
- 标签：`#配置` `#布局` `#回归`；日期：2026-09-09。
- 方法：双栏页面使用 MCM Helper 原生 `topToBottom` 与列首标题 `position=0/1`，保留后续控件顺序；用结构回归检查列归属及双语一致性。布尔默认值同时核对 C++ 初始值、MCM/ SKSE 默认 INI、帮助文案和原生绑定。
- 原则：菜单中当前关闭不等于默认关闭；保存设置优先级需要单独判断，修改发布默认值不能擅自覆盖用户保存文件。静态布局通过仍需游戏内验证。[关联 S2](../stages/s2-mcm.md)。

## UI 构建链
- 标签：`#构建` `#回归`；日期：2026-09-08。
- 现象：源码更新不代表游戏加载的 SWF 已更新。
- 方法：重编译、嵌入、反编译回归、哈希与安装包比对依次验证。
- 原则：发布资源和源码一同审阅；静态成功不替代 VR 视觉验收。[关联 S1](../stages/s1-questlist.md)。

## 装饰内内容安全区
- 标签：`#AS2` `#布局` `#回归`；日期：2026-09-09。
- 现象：舞台边界测试通过，但正文和目标分隔区仍超出自身标题装饰；只扩宽内容的自适应与固定素材宽度不一致。
- 方法：从实际装饰的边界建立独立内容安全区，所有正文、分隔线和目标行共用；局部遮罩仅包住生成内容，保留原装饰与动画。长文本先换行，再走既有缩小/省略，不通过单独扩宽突破装饰。用真实素材尺寸、长单词、字体恢复和父级变换测试验证局部几何。
- 原则：舞台安全不等于组件内部安全；内容测量与裁切必须共享同一坐标系和边界。静态/反编译测试不替代 VR 字形及贴图裁切验收。[关联 QuestList](quest-list.md)。

## 空容器的布局所有权
- 标签：`#AS2` `#布局` `#回归`；日期：2026-09-09。
- 方法：不可见 MovieClip 使用独立逻辑宽高与局部原点，子元素只接收容器分配的尺寸；统一排版函数测量、排列并累计高度。原始装饰决定自然宽度，外层安全区只消费逻辑高度，遮罩由最终布局生成而不参与正常测量。
- 原则：MovieClip 的 `_width/_height` 是绘制边界/缩放属性，不等于前端 Box 的 CSS 布局尺寸；不能让子元素或未裁切的导入素材反向决定容器宽高。局部坐标改变后，所有高度与裁切判断必须同步转换，测试应覆盖空区、嵌套变换、超大素材和隐藏恢复。[关联 QuestList](quest-list.md)。

## 原版时间轴纳入布局根节点
- 标签：`#AS2` `#SWF` `#布局`；日期：2026-09-09。
- 方法：对需要保留的原版时间轴实例，在构建期新增一帧包装Sprite，以原符号作为Header子级，再将原放置引用切换到包装器；保留原位置/透明度关键帧及所有其他非脚本标签。运行时保留原对象兼容引用，生成内容放入独立Body，只有Body接受局部遮罩。
- 原则：不要通过运行时复制或删除时间轴实例模拟浏览器的reparent；原始素材完整性、完整动画、逻辑高度和遮罩层级应分别验证。XML往返会重排缩进，结构对比仅忽略格式空白，不剥除有意义的文本。[关联QuestList](quest-list.md)。

## 省略决策与坐标空间
- 标签：`#AS2` `#VR` `#布局`；日期：2026-09-09。
- 方法：适配、裁切、标签预留全部在同一根坐标中比较完整矩形，不用单个Y值模拟二维坐标变换。缓存记录最终几何，溢出结果也必须在几何变化后重新求解。先计算真正隐藏的完整段落/行，再决定是否预留省略号；保留原本可读的描述，标签放在最后可见内容后。
- 原则：绘制余量不是缺失内容；省略号不能为了自身而挤掉可读正文。截图物理空间不等于Flash安全区，必须用运行时Stage、父级变换、完整/可见底边及行状态核实，不能因模拟通过就扩大VR安全边界。[关联QuestList](quest-list.md)。

## 调试叠加层作为布局观察者
- 标签：`#调试` `#AS2` `#VR`；日期：2026-09-09。
- 方法：可视化调试应由现有调试级别门控，并作为布局树之外的观察者。将逻辑矩形四角转换到同一坐标空间后绘制，分别标注根坐标AABB和局部尺寸；隐藏元素保留诊断几何。复用标签并以几何签名限制重复绘制，关闭/卸载清理。
- 原则：调试绘制不能反向参与`getBounds`布局、扩大遮罩或绕过可见性门控；调试信息必须标明坐标空间与真实安全线的含义。不要把HUD根坐标当作VR物理像素或UV测量。[关联QuestList](quest-list.md)。

## 原生UI首次初始化必须同步设置
- 标签：`#原生` `#初始化` `#诊断`；日期：2026-09-09。
- 经验：UI新增设置必须检查所有实际创建路径，而非只检查设置热重载或兼容分支。真实日志中MCM已保存Debug、嵌入式QuestList正常显示，但enabled=false，证明缺少首次初始化同步。将首次嵌入、兼容补丁和热重载共用同一设置应用函数，加入覆盖真实嵌入分支的回归，并记录requested、method与SWF实际state。先证实开关已到达运行时，再排查渲染和坐标。

## INI首节与UTF-8 BOM兼容
- 标签：`#配置` `#原生` `#回归`；日期：2026-09-09。
- 现象：用户保存了Debug(1)，最新原生分发也执行，但requested=false；后续QuestList设置正常读取。
- 方法：检查实际保存文件原始字节，发现`EF BB BF`位于首个[Debug]节之前。用相同Windows配置API对原文件和去BOM临时视图做反例测试，确认仅首节被忽略。为原INI读取入口增加临时规范化视图，保留原文件与三层优先级，并测试源文件不变、所有节可读及临时清理。
- 原则：文件存在/日志显示Loaded不等于每个键成功读取；排查应记录实际有效值和来源。不要为修复编码兼容而删除用户保存值或盲目重置MCM。[关联MCM](mcm.md)。

## 在保留SWF ABI的前提下拆分AS2
- 标签：`#AS2` `#重构` `#构建`；日期：2026-09-09。
- 方法：将原类/时间轴入口保留为声明和模块清单，按职责拆分函数，构建期组合后再交给原编译器；显式追踪所有模块哈希，拒绝重复、循环、缺失及孤立文件。重构前冻结当前源码与测试基线，逐函数对比实现，再由真实SWF反编译回归验证链接、动画与行为。测试拆分须按完整语法块处理嵌套回调，不能靠第一个文本`});`猜测结束位置；迁移后核对用例清单与总数。
- 原则：源码组织不应无故改变运行时类层级、加载边界或原始资源。将模块组合、编译、模拟、打包及VR验收分别记录；源码函数体相同不等于二进制必然逐字节相同，也不等于实机效果已验证。[关联QuestList](quest-list.md)。

- 原则：默认设置更新不能擅自覆盖用户保存值；不要为修复模组文件而改动 MO2 优先级或启用状态。安装哈希成功与游戏实际加载、VR 视觉验收分别记录。[关联 S2](../stages/s2-mcm.md)。

## 设置退役闭环
- 标签：`#配置` `#兼容` `#回归`；日期：2026-09-09。
- 方法：设置彻底退役时同时清理默认 INI、运行时变量/分发/注册、跨语言/API 入口与兼容行为测试，并加入“不再存在”的负向断言；历史反编译和明确标注退役的工具可保留作参考。
- 原则：UI 隐藏或运行时忽略都不等于“设置已删除”；发布链里仍能解析/调用的入口都属于活动残留。[关联 S2](../stages/s2-mcm.md)。

## Flash 动画与设置缩放
- 标签：`#动画` `#回归`；日期：2026-09-08。
- 现象：设置写入/重载正常，但动画容器缩放不稳定。
- 原因：SWF 关键帧写入父容器矩阵；缩放该容器还会影响内嵌任务列表。
- 方法：把用户缩放应用到不参与父容器动画的文字层，使用反编译行为测试验证独立性与动画模拟。
- 原则：只检查接口存在无法证明 UI 设置在时间轴播放后仍有效；最终仍需渲染实机验收。

## SWF 素材黑边与遮罩
- 标签：`#SWF` `#描边`；日期：2026-09-09。
- 清空运行时 filters 不会移除矢量 LINESTYLE2 黑边。缩小后黑边过粗时检查 noVScaleFlag/noHScaleFlag、宽度及 miter 接角；保留原始素材，由构建脚本修正并纳入发布哈希。
- 内容遮罩应在最终排版后更新，使用内容边界加描边余量；舞台遮罩不能约束舞台内部的多余绘制。截图中未定位到具体实例的残片仍须实机取证，不应把遮罩测试通过当作根因证实。

- 目标行的裁剪单位必须覆盖文字、图标及滤镜余量；单独使用 textHeight 会漏算高于文字的菱形。初建和扩宽应共用测量函数，并测试短文字、描边差一像素无法容纳时整行隐藏。

## 图标缩放须保留素材基础矩阵
- 日期：2026-09-09；标签：`#SWF` `#缩放`。
- UI 百分比是相对设计尺寸，不能直接写入原始比例非 100% 的图标。海拔箭头原始比例约 35%，应保存初始矩阵并乘以距离百分比；不要每帧读取已改后的比例累乘。
- 测试模型应复现素材实际初始比例，并分别改变名称和距离验证独立性。名称放大后的跨贴图区显示已获用户确认，不能继续归因于装饰背景。

- 距离读数组合居中：autoSize=center 处理文字尺寸变化，不替代显式缩放后的固定锚点。组合宽度应只计入可见箭头，并在状态切换后测量；箭头注册点不一定在左缘，应以 getBounds 补偿。回归覆盖位数、单位、显隐和多次缩放防止累计漂移。

## C++ 与资源拆分验证
- 日期：2026-09-09；标签：`#重构` `#构建` `#Windows`。
- 公共头缩成接口时必须同批落地私有实现；原来依赖传递包含的文件要显式包含所用接口，私有头优先使用同目录路径。保留函数体基线比对，并用真实编译/链接验证跨编译单元符号。
- 资源搬迁先比对文件哈希，再更新构建链并真实重建；不能只改清单使检查变绿。主包与语言覆盖分别保持游戏Data目录，源素材与生成中间件不直接打包，最终ZIP按文件集合及哈希核对。
- 含中文的Windows BAT须保留CRLF。通用文本重写脚本若写成LF，CMD可能截断命令；遇到碎片式“不是内部或外部命令”先核对真实编码与换行，不盲目改路径斜杠。


## AS2调试层创建不等于绘制完成
- 2026-09-09：诊断也必须遵守TextField与MovieClip的API边界；测试模型继承便利方法会掩盖真实运行时缺失方法。对名称锚点禁用getBounds/localToGlobal/globalToLocal，验证父容器四角转换和所有线段坐标有限。
- 记录实际绘制区域数，完成绘制后再提交缓存签名，避免把空容器的visible=true当作成功。

## Passenger分支回归与调试坐标
- 回归必须启用真实活动模式并读取编译后的配置。仅测root分支、在模拟器硬编码旧配置会漏掉70/25覆盖110/90的缺陷。
- 几何、绘制容器、裁剪窗口必须使用同一坐标系。根层叠加框应从内容本地四角转换到根层，不能直接绘制Target坐标；调试只画线条/无底色文字，不使用未绑定的填充遮罩。
- 发现已有源码修复时保留并核验构建清单；源码变化不等于安装SWF已经更新。

## 省略号与提交验收
- 先计算不预留省略号时可显示的正文和目标，再预留标记；标记不能挤掉最后一条可读目标。紧空间时保留目标比显示省略号优先。
- AS2 TextField的显示宽高包含自身缩放，模拟器必须区分显示尺寸与本地文字指标。
- 多批提交是当前工作区的职责拆分，不伪造此前未提交的实验历史；中间提交可能依赖后续模块，完整构建验收针对最终组合。
